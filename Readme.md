## 📌 Descripción

Herramienta que resume textos extensos automáticamente, extrayendo las ideas más importantes usando procesamiento de lenguaje natural en español.

---

## 🎯 Objetivo

Ahorrar tiempo a usuarios que necesitan procesar grandes cantidades de texto, entregando un resumen claro y preciso de forma instantánea.

## 🚀 ¿Cómo ejecutarlo?

1. Abre el archivo `.ipynb` en **Google Colab**
2. Ejecuta las celdas en orden
3. Pega el texto que deseas resumir cuando se solicite
4. El sistema devuelve las ideas principales automáticamente
